# RouteLog v0.05

GPS移動記録・ルート履歴管理Webアプリの初期実装です。

## v0.01で入っているもの
- サンプルデータ入りホーム画面
- 過去ルートの地図重ね表示
- カテゴリ別ON/OFF・色分け
- 地図をタップして「この付近を通った履歴」を確認
- GPS実測記録
- 滞在候補検出
- 滞在判定の距離・時間を設定から自由変更
- 手動で出発地点・到着地点を指定して記録追加
- 自由カテゴリ・タグ管理
- GPS実測 / 手動登録の区別
- カレンダー / 簡易統計
- PWA対応

## 注意
GPS記録はブラウザの制約上、画面OFF・バックグラウンドで長時間継続できない場合があります。
この版はローカル保存（localStorage）です。Supabase同期は次版以降で追加予定です。

## v0.04
- 地図ページのズーム + / - を右下へ移動
- 表示内容（カテゴリ選択）を折りたたみ可能に変更
- 「記録」ページを開いただけではGPS記録を開始しない
- 記録ページ内の「記録開始」で開始
- GPS記録中はWake Lockを要求し、画面消灯をできるだけ防止
- 記録途中のGPS点をローカルへ随時退避
- 未完了記録がある場合は再開可能
- GPS実測線は細かいGPS点をそのまま保持
- Supabaseクラウド同期を追加
- 記録終了時・手動登録時にクラウドへ自動保存
- カテゴリ・タグ・滞在判定設定もクラウド同期
- 設定画面からSupabase接続情報を入力可能

### Supabase初期設定
1. `SUPABASE_SETUP.sql` をSupabaseのSQL Editorで実行
2. AuthenticationでAnonymous Sign-Insを有効化
3. RouteLogの「設定 > クラウド同期」にProject URLとAnon/Publishable keyを入力
4. 「保存して接続」→「今すぐ同期」


### PC・スマホで同じデータを使う場合
Supabase AuthenticationでGoogle Providerを有効にし、RouteLog設定画面から「Googleでログイン」を使います。
同じGoogleアカウントでログインして「今すぐ同期」を押せば同じクラウド領域を使用できます。
匿名接続は、出発前にすぐ試すための端末単体バックアップ用です。
